# PNG 转 Windows ICO 图标生成器

一款基于 Python 和 CustomTkinter 开发的桌面应用，用于将 PNG/JPG/BMP 图片转换为符合 Windows 标准的 ICO 图标文件。

## 功能特性

- ✅ **智能裁剪**：自动将非正方形图片裁剪为正方形，支持自定义裁剪区域选择
- ✅ **多尺寸打包**：生成包含 16×16、32×32、48×48、64×64、128×128、256×256 六种标准尺寸的 ICO 文件
- ✅ **透明通道保留**：完美处理 PNG Alpha 通道，保持图标透明效果
- ✅ **拖拽支持**：支持拖拽图片到应用窗口快速载入
- ✅ **实时预览**：左侧显示原图和裁剪框，右侧实时预览 256×256 效果（带透明网格背景）
- ✅ **自定义裁剪**：可自由调整裁剪区域位置和大小，始终保持正方形
- ✅ **超大图片保护**：自动处理超过 5000px 的图片，防止内存溢出

## 快速开始

### 方式一：直接运行 EXE（推荐）

1. 打开 `dist/IconGenerator.exe` 即可运行
2. 无需安装 Python 或任何依赖

### 方式二：源码运行

```bash
# 克隆或下载项目
cd Icon_Generator

# 安装依赖
pip install -r requirements.txt

# 运行程序
python main.py
```

## 使用方法

1. **选择图片**：点击「选择图片」按钮或直接拖拽图片到左侧预览区
2. **调整裁剪区域**：
   - 拖动蓝色裁剪框内部可移动位置
   - 拖动四角蓝色小方块可调整大小（始终保持正方形）
   - 点击「重置裁剪」恢复默认居中裁剪
3. **查看效果**：右侧预览区实时显示裁剪后的 256×256 效果
4. **生成 ICO**：点击「生成 ICO 文件」按钮，选择保存路径即可

## 技术规格

### 支持的输入格式

- PNG（推荐，支持透明背景）
- JPG/JPEG
- BMP

### 输出格式

- ICO（Windows 标准图标格式）
- 包含 6 种尺寸：16×16、32×32、48×48、64×64、128×128、256×256
- 每像素 32 位（RGBA），支持透明效果

### 系统要求

- Windows 10 / Windows 11
- Python 3.8+（源码运行时）

## 依赖项

- `customtkinter>=5.2.0`：现代化 GUI 框架
- `Pillow>=10.0.0`：图像处理库
- `tkinterdnd2>=0.3.0`：拖拽功能支持（可选）

## 打包为 EXE

如果需要重新打包：

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --icon=text.ico --name=IconGenerator main.py
```

打包后的文件位于 `dist/IconGenerator.exe`

## 注意事项

1. 建议使用至少 256×256 像素的图片作为输入，以获得最佳效果
2. PNG 格式支持透明背景，是推荐的输入格式
3. 裁剪区域最小为 16×16 像素
4. Windows 可能会缓存图标，如果更换后没有立即显示，按 `Ctrl+Shift+Esc` 结束 `explorer.exe` 进程并重新启动
